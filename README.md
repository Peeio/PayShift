# 📅 Gestor de Turnos y Nómina

Una aplicación web intuitiva y ligera para organizar tus turnos de trabajo, consultar el rendimiento anual y calcular una estimación personalizada de tu nómina.

## 🌟 Características principales

- **Calendario Mensual y Anual:** Visualiza tus turnos, consulta las estadísticas del año y compara los días trabajados con la planificación anual.
- **Turnos Personalizados:** Crea hasta 12 tipos de turno y ajusta sus nombres, horarios, turnos partidos, colores e imágenes de fondo.
- **Asignación Rápida y Pack Guardia:** Cambia turnos de días individuales, selecciona varios días o rangos completos y aplica automáticamente el patrón de guardia de 12 días.
- **Notas Diarias:** Añade notas personales a cada fecha para tenerlo todo organizado.
- **Cálculo de Nómina Ajustable:** Estima devengos y deducciones incluyendo sueldo base, complementos, prorrata de pagas extra, nocturnidad, guardias, horas extra MG/NG e IRPF. También puedes añadir complementos salariales propios.
- **Cuenta Personal:** Accede con correo y contraseña o con Google, verifica tu correo y recupera tu contraseña cuando lo necesites.
- **Datos y Copias de Seguridad:** Guarda tus datos en Firebase, conserva las cinco copias automáticas más recientes y exporta o importa tu información mediante archivos JSON.
- **Interfaz a tu gusto:** Alterna entre modo claro y oscuro, personaliza tu avatar y utiliza la aplicación desde ordenador, tablet o móvil.

## 🛠️ Tecnologías

HTML, CSS y JavaScript, Tailwind CSS, Lucide Icons y Firebase Authentication / Cloud Firestore.

## 🚀 Puesta en marcha

La aplicación se encuentra en `Index.html` y no necesita un proceso de compilación. Para ejecutarla con tus propios datos, configura el proyecto de Firebase, habilita los métodos de acceso que vayas a utilizar y configura las reglas de seguridad de Cloud Firestore antes de desplegarla.

> **Nota:** Los importes de nómina son estimaciones basadas en los parámetros configurados; conviene contrastarlos con la nómina real y las condiciones laborales aplicables.
